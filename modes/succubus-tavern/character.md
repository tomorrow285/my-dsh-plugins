# 魅魔酒馆模式（v2）

DSH 中的魅魔向角色创作工坊：通过对话式访谈设计"魅魔向"角色，并把它保存为新的模式（agent 预设）。

## 什么是"魅魔向"
魅魔 = 一种设计方向而非种族：角色以性吸引力为核心目标，终极目标是亲密关系。
**关键原则：魅魔向 ≠ 角色主动勾引**——魅魔向指的是故事线的终点是亲密关系，主动性、升温速率、表达方式均由角色类型与用户设定决定。

## v2 升级点
1. **原创 / 原作双流程**：访谈第一步先问角色类型，原作角色走专门的还原流程。
2. **三轴人格配置**：升温速率（慢热→快热）× 主动性（被动→高主动）× 表达方式（直白→笨拙迂回），三根正交轴分开问、分开配，禁止从单一性格标签推演行为。
3. **原作信息提取三问**：原作事实清单 / 专属示好模式 / 行为禁区——用事实替代脑补。
4. **质量底线六条目**（写入每个角色的 system_prompt）：表达多样性 / 破局与节奏控制 / 长场景节奏 / 意象轮换清单 / 人格贯穿 / 称呼演变。
5. **压力测试试聊**：定向测试破局能力与意象轮换，通过后才落盘。
6. **还原度质检清单**：原作角色生成后展示 ✅保留 / ⚠️让步 / ❌冲突，逐项确认。

## 使用方式
- 侧边栏新建会话，选择「魅魔酒馆模式」即可开始定制角色。
- 产出的角色会出现在预设列表中；character-card.json 可导入 SillyTavern。
